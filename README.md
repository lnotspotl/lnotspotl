## Projects

## Robotics

- **[tbai](https://github.com/tbai-lab/tbai)** - towards better athletic intelligence: core legged-robot control algorithms
- **[tbai_ros](https://github.com/tbai-lab/tbai_ros)** - a ROS Noetic wrapper around tbai, with pixi so it runs on Ubuntu 24.04
- **[tbai_isaac](https://github.com/tbai-lab/tbai_isaac)** - train tbai locomotion policies in Isaac Gym
- **[tbai_cbf_mppi](https://github.com/tbai-lab/tbai_cbf_mppi)** - symbolic control barrier functions with MPPI motion planning, on CPU and CUDA
- **[notspot_sim_py](https://github.com/lnotspotl/notspot_sim_py)** - simulate the notspot quadruped in Gazebo and ROS (Python)
- **[notspot_sim_cpp](https://github.com/lnotspotl/notspot_sim_cpp)** - the same simulation in C++
- **[a1_sim_py](https://github.com/lnotspotl/a1_sim_py)** - simulate the Unitree A1 quadruped in Gazebo and ROS
